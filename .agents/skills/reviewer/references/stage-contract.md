# Reviewer 阶段契约

## 输入

有效契约、具体风险、授权范围、相关变更基线、验证证据、受影响文档；聚焦时增加前轮问题和修复差异。fresh 表示未参与该次实现，不表示数量越多越好。

## 必查结果

- 预期行为与可观察证据一致；权限、数据、兼容及相邻回归按实际范围检查。
- 路线/风险有具体依据，没有把产品能力伪装成轻量维护，也不把 Phase 当作风险。
- 当前文档已对账，历史约束不复活；实现/验证/审查/发布状态没有混写。
- 证据适用于当前相关代码和环境，未提交的其他任务修改不被冒认覆盖。

## 输出

```markdown
范围与基线：
风险及依据：
结论：通过 / 有条件通过 / 不通过 / 无法审查 / 中断
问题：证据、具体后果、建议
验收覆盖与文档核对：
本轮关闭/剩余问题、新增证据：
批量复查时：覆盖条目 ID 与基线、可关闭项/须保留项、回执依据（供主会话清理队列）：
残余缺口和恢复条件：
```

同一输入去重；有实质修复时一次一个聚焦复核，连续两轮无进展或预算用尽暂停。详细规则见[共同契约](../../../../.creator/references/workflow-contract.md)。例外授权不能改写为通过。

## Examples

同一 diff 已有 reviewer：复用，不重复启动。

第二次复核后最终问题已修复且有失败回归：可对新 diff 聚焦，不因曾用两轮永久阻塞。

同问题无新证据，要求一直找人直到通过：暂停并说明恢复需要的实质改变。

Selected model is at capacity：中断，保存有效检查与剩余范围，不把宿主错误当不通过。
