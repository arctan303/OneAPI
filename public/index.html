临时从可信局域网访问时，直接传入启动参数：
npm start -- --host 0.0.0.0 --port 9090 --lan
--lan 会为当前私网地址生成允许的精确 Origin；通配监听地址不能直接作为访问地址。请使用启动输出列出的局域网 URL。
需要持久化配置？
源码目录运行 npm run configure:server；独立部署包运行 node configure.mjs。向导保存配置后需重启服务。
