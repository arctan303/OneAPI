## 范围与非目标

- 主交付改为单Node.js进程、SQLite持久化、原静态管理后台和HTTP API；生产不运行Wrangler/Miniflare/workerd，不要求Docker、Redis、独立数据库或Worker转发。
- 复用既有业务与公开接口：管理员口令/会话、Access两参数开关及兜底、Codex设备授权、官方模型/额度、key政策、Responses/Chat文本/工具子集/流式/思考程度及日志保留。
- 默认localhost安全启动；服务器可显式绑定地址并配置公开HTTPS origin，Host/Origin/CSRF和Access JWT验证不得依赖可伪造代理头。API key调用路径不受交互式Access门禁影响。
- 旧本地OAuth、API key、Access/日志配置及已结束历史日志提供离线/显式迁移方案：先验证来源和目标、只写新目标，不覆盖源库，失败可回旧入口。保持加密，禁止凭据落入终端或包内；不迁移旧管理员会话、进行中的登录、租约、速率窗口和缓存，迁后用管理员口令重新进入后台，Codex账号无需重新授权；不默认迁移云端账号或改现有域名。
- 提供直接启动、配置示例、systemd/反向代理部署和备份恢复说明，可提供可选Docker示例但不是必需。量化产物体积/生产依赖/空闲内存，仅报告本机实测，不编造服务器指标。
- 方向1有界研究最多8个新增/有新证据候选，核对源码和成功证据；不为研究重复发送已失败的真实Worker请求。
- 不含多账户/转售/计费、新协议、UI大改、未指定服务器实际部署、新增付费云服务、DNS迁移或删除现有Worker。

3. 功能验证：隔离Mock HTTP与SDK两协议/流式/思考程度、key模型白名单和日志、管理员会话/跨站、Access合法/非法JWT、取消只影响对应调用、并发限制、持久化重启、事务失败回滚、日志清理；关注行为而非测试数量。
