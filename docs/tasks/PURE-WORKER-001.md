# PURE-WORKER-001：单 Worker 参考实现与无令牌网络观测

状态：本轮资料核查、实现、四路径观测和临时资源清理完成；纯 Worker 上游仍受阻。2026-09-07。属于 [Phase-02 后续路线](../dev-plan/phase-02.md#单-worker-后续路线2026-09-07) 的前两项准备。

目标：找到可复现的 Codex 订阅纯 Worker 实现，建立本地 Node / workerd / 云 Worker / DO 出站差异表，为最多两个具体假设提供依据。预期最终仍是单 Worker 自身访问上游，无常驻外部服务。

范围：只读公开项目与官方资料；独立无令牌合成探测、临时 oneapi-network-probe Worker 及自身 ProbeDO；本地 miniflare 与同一 collector 对照。非目标：改生产鉴权、读取或传输 OAuth、迁移账号 DO、生产 Node 中转、改其他 Worker 或 DNS。

依赖与基线：EGRESS-001 已完成（同云端令牌 Node 200，原 Worker 403）；原 Worker 未修复且临时 relay 已关闭。保留当前未提交修改，不能把其验证写成本任务成果。

授权：用户允许本项目隔离 Worker/存储测试，并在已说明上述路线后要求“那就开始吧”。不对外发消息。实施 Sol/high，资料 Luna，根代理负责集成和有限实际观测。

风险 R1（按当前设计）：独立无凭据探测，固定自身 collector 目标和路径，白名单元数据、无外部可选 URL、无持久账号数据。不反射 authorization/cookie；合成探测不读取 .dev.vars。若新增凭据访问或改变生产鉴权则升级 R2 并独立审查后执行。

验证：本地 fixture 覆盖固定请求、元数据过滤、无递归和任意出站；构建及部署前检查，资源冲突检查；线上与本地四条合成 collector 观测（Node、workerd、Worker、DO各一次，无自动重试），记录失败也算一次。若工具本身失败，修复后只补失败路径并记录原因。所有查询 OpenAI 的调用数为零；后续真实目录实验必须先写具体假设和沿用 Phase-02 预算。

清理：实验结束删除本次新建无数据诊断 Worker 与自身空 namespace（如平台允许）；只按清单中本次新增资源 ID 操作，保留源码、配置和脱敏证据。若保留资源或删除失败须明确记录，不触碰原 oneapi。

恢复：实现/验证/部署分别记录。无可验证假设时停止真实上游调用，保留差异与待补证据，不能宣布纯 Worker 可用。

最终证据见 [PURE-WORKER-001](../verification/PURE-WORKER-001.md)。没有找到支持新增真实目录实验的修复假设，本轮账号上游调用为零。恢复依赖上游/平台反馈或可复现的纯 Worker 成功路径；诊断工具独立 R1 自查完成，例行复查待队列处理。
