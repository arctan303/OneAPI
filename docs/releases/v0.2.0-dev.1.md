# OneAPI v0.2.0-dev.1

本开发版将 OneAPI 的主要部署方式改为轻量单服务器：一个 Node.js 进程和 SQLite，生产运行无需 Docker、Wrangler、Miniflare、Redis 或外部数据库。

## 安装

下载附件 `oneapi-server-0.2.0-dev.1.tar.gz` 和对应 `.sha256` 文件，使用 Node.js **24.x（>=24.15.0，<25）**。解压后进入 `server/`，无需 `npm install`：

```sh
node setup.mjs
node --env-file=.env oneapi.mjs
```

用编辑器查看本机 `.env` 中的 `ADMIN_API_KEY`，在 `http://127.0.0.1:8787/` 登录管理员后台，再连接自己的 Codex 账号并创建客户端 API key。每位安装者生成自己的配置、授权自己的账号。

[完整安装教程](https://github.com/arctan303/OneAPI/blob/v0.2.0-dev.1/docs/INSTALL.md) · [服务器 HTTPS / systemd / Access 部署](https://github.com/arctan303/OneAPI/blob/v0.2.0-dev.1/docs/DEPLOYMENT.md)

仓库为私有：下载需要访问权限，或由所有者转发发布附件。GitHub 自动生成的 Source code 压缩包是源码，直接安装请选上面的 `oneapi-server-*.tar.gz`。

## 本版能力

- 保留管理员登录、Cloudflare Access 两参数配置与管理员口令兜底。
- Codex 设备码授权、官方模型目录、可用思考程度及官方额度窗口。
- `/v1/models`、`/v1/responses`、`/v1/chat/completions`，包含已实现的流式与函数工具兼容子集。
- API key 模型白名单、到期/并发控制、基础日志和可选完整请求/响应日志。
- 旧本地存储离线迁移；保留加密账号、API key 和已完成日志，源库不变。升级和迁移前按教程备份数据与原加密密钥。

## 验证与已知边界

原生运行时、HTTP/SDK 模拟调用、存储迁移、取消和鉴权已验证，独立复核通过。本机真实 `gpt-5.5` 的模型目录、官方额度、Responses、Chat SSE、思考程度和日志已通过。

这是供试用的预发布版。Linux systemd/Caddy 模板尚未在目标服务器实机验收，其他服务器出口须各自验证。可用模型和额度以各自账号的官方返回为准；未返回五小时窗口时显示未知。

Cloudflare Access 只保护管理入口；`/v1` 应使用 API key，避免交互式登录跳转。现有纯 Worker 实验仍未跑通，不作为本版生产部署方式。

反馈请提供 Node 版本、操作系统、HTTP 状态、应用错误码及复现步骤；去除密钥、Cookie、OAuth 凭据和私人请求内容。
