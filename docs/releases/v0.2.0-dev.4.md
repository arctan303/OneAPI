# OneAPI v0.2.0-dev.4（开发测试版）

本版让 OneAPI 可直接作为 Codex 0.153.4 的自定义 Responses provider，并合入本地管理后台的完整交互与视觉优化。

- `GET /v1/models?client_version=0.153.4` 在标准 `object/data` 之外返回同权限过滤的原始 Codex `models` 目录，保留 shell、基础指令、reasoning、verbosity 和未来能力字段；普通 OpenAI SDK `models.list()` 保持兼容。
- 原生 Responses 请求保留 `additional_tools`、消息 ID、加密 reasoning、函数/自定义工具调用与工具输出，以及 `include`、`prompt_cache_key`、`text` 和白名单 `client_metadata`；当前 Codex 0.153.4 必需的客户端 `namespace` 声明可通过，托管工具类型仍明确拒绝。
- 未知顶层生成参数不再阻断：字段值不会转发上游，安全化后的字段名进入基础日志和 `X-OneAPI-Ignored-Parameters`。已知但需要服务端状态的 `store:true`、`background:true`、`previous_response_id`、`conversation` 等仍明确拒绝。
- 只转发 Codex feature/window/turn/session 等经过审查的元数据头；客户端 Authorization、Cookie、User-Agent、Host 与任意未知头不会越过网关，OpenAI 账号凭据仍由 OneAPI 服务端替换。
- 后台升级为分区导航，增加额度分组与重置倒计时、真实模型/思考程度选择、手动模型入口、密钥创建/编辑弹窗、日志快捷筛选/详情/下载等交互；桌面和 390px 移动布局已验收。额度与日志状态样式已改为严格 CSP 可用的外部类和原生 progress。

## 安装与升级

需要 Node.js 24.x（>=24.15 且 <25）。下载 `oneapi-server-0.2.0-dev.4.tar.gz` 与对应 `.sha256`，先校验再解压。首次安装运行 `node setup.mjs`；已有 dev.1/dev.2/dev.3 用户停止旧进程、备份环境文件与数据目录，然后让 dev.4 继续使用原三个 secret 和同一外置 `DATA_DIR`，不需要数据库迁移或重新授权。

Codex 配置必须使用 `wire_api = "responses"`，`base_url` 指向 OneAPI 的 `/v1`，调用 key 通过 `env_key` 指定。可复制示例见包内 README 和 API.md。

本次只发布源码与单服务器安装包，不自动更新远端 Node、Cloudflare Worker 或 Access 策略。生产升级后仍应验证健康检查、Codex 模型刷新和一条真实调用。
