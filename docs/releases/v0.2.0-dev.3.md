# OneAPI v0.2.0-dev.3（开发测试版）

本版处理Cloudflare登录返回报错、Codex订阅模型目录漏项，以及Hermes自动附带生成参数时被400拒绝的问题。

- 登录入口统一到/admin/login，根地址整页跳转，登录后进入/admin/后台。Cloudflare保护/admin/*时先完成CF认证；无CF保护时使用居中管理员口令表单，不再增加CF按钮。旧/admin/access/login回跳仍完整验签，管理数据接口继续同源校验和鉴权。
- 模型目录保留订阅账号实际上游列出的可选模型，避免把supported_in_api=false当作订阅不可用而过滤Spark。模型仍受上游账号授权和每key白名单限制，不硬编码或保证所有账号有Spark。
- Chat的max_completion_tokens/max_tokens、Responses的max_output_tokens，以及temperature/top_p，校验后兼容忽略。基础调用日志显示未生效参数，无需开启完整正文；成功响应头X-OneAPI-Ignored-Parameters同时告知客户端。输出上限和采样设置不会生效，token用量沿用真实上游值。
- 保留模型、输入/系统指令、思考程度、函数工具和流式能力；非必要参数继续使用默认行为，不新增一长串配置。未知关键字段仍明确报错。

## 安装与升级

需要Node.js 24.x（>=24.15且<25），安装包无需npm install。下载本版tar.gz与.sha256并校验，解压后首次安装运行node setup.mjs，再按包内INSTALL.md启动。仓库为private，下载者需要读取权限。

已有用户先停止旧进程并备份.env及数据目录，在独立版本目录解压，继续使用原凭据和外置绝对DATA_DIR。不要重新setup覆盖配置，不要同时启动两个进程访问同一数据库。新增日志摘要字段由启动时幂等补齐，旧日志保留。回滚前停止新版并保留当前数据副本，再使用旧二进制；如恢复升级前备份，应注意备份后的记录不在旧备份中。

Cloudflare应用开关和边缘策略需要保持一致；API的/v1/*不应被交互式登录拦截。管理员口令不能绕过Cloudflare边缘门禁，卡住时先在Cloudflare控制台关闭或收窄策略。完整说明见包内INSTALL.md和NETWORK.md。
